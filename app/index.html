03 · ПРОФИЛЬ УСЛОВИЯ▼

Погода выкл — не учитываются ни дождь/снег, ни фары. Жёсткий cap — потолок скорости по погоде (лёд→15, снег→25).
Тап по карте — точка A → B → C… (до 10). Тап между точками вставит новую на своё место, маркер можно перетащить.
ОПТ / СРЕД / ПЕСС — общий расчёт на крейсерской скорости. МАРШРУТ — пошаговый: уклоны, ветер по каждому участку, светофоры туда и обратно.
